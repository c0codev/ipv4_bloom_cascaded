# 🐾 Contributing

💜 First of all, **thank you** for reviewing the repo and reading this; it really means so much, I hope you've liked the code.

If you believe this project is **meaningful** in any way, the best way to show support of it is by **helping to improve it**.
For that reason **contributions**, **bug reports**, and performance **optimizations** are more than welcome 🫶. 

---

If you're interested to contribute to the project, the steps to follow are detailed below:

1. 🖨️ Fork the repository.
2. 💻 Create your feature branch `(git checkout -b feature/my-contribution)`.
3. 📀 Commit your changes `(git commit -m 'Add some contribution')`.
4. ⬆️ Push to the branch `(git push origin feature/my-contribution)`.
5. 📥 Open a Pull Request.
